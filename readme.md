# Travel-Mind

Travel-Mind is a full-featured travel accommodation and booking platform.

## Setup & Installation
```bash
npm install
npm start
```

## Environment Variables
- `CLOUD_NAME`
- `CLOUD_API_KEY`
- `CLOUD_API_SECRET`
- `MAP_TOKEN`
- `ATLASDB_URL`
- `SECRET`
- `RAZORPAY_KEY_ID`
- `RAZORPAY_KEY_SECRET`
